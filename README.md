# 强多啦哈（Chandrahas）截图裁拼

把一堆 FF14 聊天截图，变成一张干净、顺序正确、自动批量打码隐私的长图。

- 随手截图，顺序混乱重叠内容？    自动按时间排好，剔除重复信息。
- 系统消息、路人喊话混在里面？    按频道过滤掉。
- 想发给别人又怕暴露 ID？        一键打码。
- 还想要图像转文本？             放心吧，包的，完全不在话下。


### 👉 [在线使用](https://kalyanirohga.github.io/Chandrahas/)

不想联网，也可以在 [Releases](../../releases) 里下载 `index.html`，双击本地文件就能用。

## 三步快速上手

**1. 游戏里先开启「显示消息时间」**

也就是让聊天栏每条消息前面带上 `[12:34]` 这样的时间。在「聊天记录」模式下，工具会靠它认出每一行、排出先后。

**2. 打开工具，切到「聊天记录」，把截图拖进来**

一次拖几十张也没问题，也可以直接按 <kbd>Ctrl</kbd> + <kbd>V</kbd> 粘贴。

**3. 在右侧调好设置，导出长图**

右侧可以设置：

1. 要保留哪些**频道**
2. **隐私打码**
3. 长图的**基础排版**

最后点右下角「**导出长图**」。弹出预览后，可以：

- 下载到本地
- 点「复制图片」，直接粘贴到聊天软件里
- 点「**图片转文本**」，把聊天变成文字，支持编辑、查找替换、复制

## 能做什么

### 🗂 自动整理聊天

- **自动找聊天框**：不用自己框，工具会认出聊天窗口在哪，输入框和标签栏不会被拼进去。被截掉一半的行也会自动丢掉。
- **自动排序**：按截图里的时间排好先后。两张截图之间如果隔了 20 分钟以上，会提醒你中间可能漏截了。相邻两张有重复的几行，会自动去掉一份。
- **其他排序方式**：左下角可以切换成「按导入顺序」或「按文件名顺序」，也可以直接在左边列表里拖动截图。

### 🎨 按频道挑消息

- 默认保留**小队、用户宏、说话、悄悄话**，其他频道收在「更多频道」里，需要的话打开开关。
- 遇到色表里没有的颜色（比如通讯贝），会自动建一个新频道，默认不保留，你看一眼再决定。
- 自己在游戏里改过频道颜色？点「从图上取色，新建频道」，在那行字上点一下就好。色号也可以直接改。

### ✂️ 一条一条地调

左边的小工具栏：

| 工具 | 用法 |
| --- | --- |
| 点选 | 点某一条消息，单独保留或排除 |
| 选取 / 取消选取 | 在图上从上往下拖一下，拖过的消息一次全部保留或排除 |
| 马赛克 | 拖出一块区域打码 |

聊天框认歪了？点右上角「**裁切聊天区域**」重新框一下，可以只用于这张，也可以应用到所有截图。

### 🖼 在聊天中间插图

鼠标移到两条消息之间，会出现「**＋ 在这里插入图片**」。点它，拖进或粘贴一张图，框出想要的部分，按 <kbd>Enter</kbd> 就插进去了。不想裁就点「整张插入」。

插了图的地方会出现黄色小标签，鼠标移上去能看到缩略图，可以调顺序、删掉、重新裁，也可以把整组或单张拖到别的位置。

### 👀 预览长图

中间上方切到「**预览长图**」，直接看拼好的成品。在这里也能移除某一段、拖动插图、打马赛克。

### 🔒 隐私处置

- **隐藏角色名**：自动找出截图里的名字（连服务器名一起），可以选马赛克，或者「**色块 + 代称**」：每个人一种颜色，名字换成「玩家 A」「玩家 B」，代称和颜色都能改。
- 名字出现在句子中间、被换行拆成两半，也能认出来。
- 点「**管理代称**」打开名单：
  - 拖动可以排序
  - 把一个人拖到另一个人的名字上，就能合并成同一个人
  - 漏掉的人可以「从图上框一个名字」补上
  - 改错了随时撤销，或者一键恢复默认
- **隐藏时间**：把每行前面的 `[12:34]` 打上马赛克。
- 如果有名字没能自动遮住，导出按钮上方会提示，点一下就跳到那一行。

### 📝 图片转文本

导出预览里点「**图片转文本**」，整段聊天会变成文字：被游戏折断的行会接回去，名字加粗，按频道上色。

识别偶尔会认错字，可以直接改，也可以用「查找替换」一次改掉同一个错字。复制时可以选带格式（贴进文档会保留粗体和颜色）或纯文本。

开了「隐藏角色名」的话，转出来的文字里名字也会换成代称。

### 📐 普通裁切

不是聊天截图也能用：切到「**普通裁切**」，在图上拖出选区按 <kbd>Enter</kbd>，一段一段加进右边的裁切顺序。拖动可以调顺序，点缩略图可以回到原图重新裁。

## ⌨️ 常用快捷键

| 按键 | 作用 |
| --- | --- |
| <kbd>Ctrl</kbd> + <kbd>V</kbd> | 粘贴截图 |

| <kbd>←</kbd> <kbd>→</kbd> | 切换上一张 / 下一张截图 |

## 🛡 关于隐私和联网

- 截图、名单、生成的长图都只在你的浏览器里，**关掉网页就没了**，不会上传，也不会留在电脑里。只有你点「下载」才会存成文件。
- 有两个功能第一次用时需要联网下载识别模型：**时间排序**（约 4 MB）和**图片转文本**（约 16 MB）。下载一次后浏览器会记住，之后几乎马上就能开始。模型在你自己的电脑上运行，没有次数限制。
- 工具只会在浏览器里记几样设置，比如频道颜色和排版选项，方便下次打开还是你习惯的样子。

## ❓ 常见问题

<details>
<summary><b>排序乱了？</b></summary>

先看截图里的时间戳是不是完整露出来了。如果聊天框认得不准、把时间戳切掉了一截，点「裁切聊天区域」重新框一下。实在不行，直接在左边列表里拖。
</details>

<details>
<summary><b>第一次转文字特别慢？</b></summary>

是在下载识别模型，不是卡住了，窗口里有进度条。之后再用就快了。
</details>

<details>
<summary><b>有的名字没遮住？</b></summary>

点导出按钮上方那句提示，会跳到没遮住的那一行。然后打开「管理代称」，用「从图上框一个名字」把它补上，所有截图里同样的名字都会一起遮住。
</details>

<details>
<summary><b>导出时提示太大？</b></summary>

浏览器能生成的图片有尺寸上限。可以把统一宽度改成「最窄」，或者分两次导出。
</details>

<details>
<summary><b>手机能用吗？</b></summary>

建议用电脑上的 Chrome 或 Edge。手机浏览器可以打开，但屏幕太小，操作会比较吃力。
</details>
